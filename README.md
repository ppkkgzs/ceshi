## PK管理器 是什么

PK管理器 是一款集 **文件管理、压缩解压、APK 处理、系统清理、FTP 传输、双栏浏览** 等功能于一体的本地工具，主要特性包括：

- 📁 **文件管理**：列表 / 网格双视图，支持复制、剪切、重命名、删除、排序、搜索与书签
- 🗜️ **压缩解压**：支持 ZIP / 7Z / TAR / RAR 等格式，内置解压，不跳转外部应用
- 📦 **APK 处理**：查看应用信息、提取安装包、直接安装
- 🧹 **系统清理**：垃圾清理、缓存清理，释放手机空间
- 🖥 **Shizuku 支持**：开启后可通过 shell 权限访问 Android/data 等受限目录（无需 Root）
- 🌐 **FTP 传输**：局域网络文件互传
- 🔍 **十六进制查看器**：二进制阅读、偏移跳转

> 本工具面向 **学习与个人使用**，请勿用于非法用途。

## 安装说明

- 支持 Android 5.0 及以上版本
- 安装时如提示"未知来源"，请在系统设置中允许安装来自此来源的应用
- 首次使用受限目录功能（如 Android/data）时，请先在软件内按提示授权 Shizuku
