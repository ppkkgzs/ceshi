核心功能

把常用工具聚合在一个应用里

📁

文件管理

单栏 / 双栏（类 MT）文件浏览，跨栏复制移动、排序、重命名、多选批量操作，识别常见与无后缀文件。

🧹

扫描清理

存储容量一目了然，缓存垃圾一键清理，检测安装包与超过 7 天未用的应用并支持一键卸载。

📦

安装包提取

提取已安装应用（用户/系统）的 APK，查看包名、版本、签名、加固、数据路径等详情。

🗜️

压缩解压

软件内压缩 / 解压 ZIP、7Z、TAR，支持加密压缩包密码解压、包内浏览与单文件解压。

💻

Shell 脚本

支持 Root / Shizuku / 普通环境运行 .sh 脚本，实时控制台输出、停止、超时控制，轻松执行复杂操作。

🔓

Shizuku 免 Root

无需 Root，经 Shizuku 直接访问 Android/data、Android/obb 等受限目录，进行增删改移。
